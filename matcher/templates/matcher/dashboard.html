Which model wins, and why

The primary model shown on every result is {% if metrics.primary_model == 'pytorch_nn' %}the PyTorch Neural Network{% else %}Logistic Regression{% endif %}, picked by comparing recall on the "Good Fit" class first and F1 as a tie-breaker (recall: {{ metrics.metrics.pytorch_nn.recall|floatformat:2 }} neural network vs. {{ metrics.metrics.logistic_regression.recall|floatformat:2 }} logistic regression; F1: {{ metrics.metrics.pytorch_nn.f1|floatformat:2 }} vs. {{ metrics.metrics.logistic_regression.f1|floatformat:2 }}). Recall matters more than raw accuracy here: missing a genuine good fit (a false negative) is a worse outcome for a candidate than being shown one extra borderline match. Each model's decision threshold (Logistic Regression: {{ metrics.metrics.logistic_regression.threshold|floatformat:2 }}, Neural Network: {{ metrics.metrics.pytorch_nn.threshold|floatformat:2 }}) was tuned on a held-out validation set to maximize recall without precision falling too low, then each model was evaluated once on a separate, untouched test set — the numbers below.
